# Mini Store Sales & Inventory Analyzer

A focused **C# console utility** designed to analyze store sales data, track item quantities, and generate quick summary reports.

## Features
- **Inventory Tracking:** Record items, prices, and available stock.
- **Sales Data Processing:** Calculate totals, revenue, and identify top-performing records.
- **Summary Metrics:** Direct console output for quick business insights.
- **Error Handling:** Protects operations against invalid inputs or null records.

## Concepts & Technologies
- **Language:** C# (.NET)
- **Data Structures:** Custom Classes & Generic Lists
- **Logic:** Aggregation calculations, data parsing, and clean modular code.
